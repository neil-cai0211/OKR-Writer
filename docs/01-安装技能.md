# 安装技能

> 装技能和连飞书是**两件事**。只装技能就能用；连飞书是可选项，见 [连接飞书](02-连接飞书.md)。

## 第 1 步：找到 skills 目录

在文件资源管理器的地址栏粘贴下面这行，回车：

```text
%USERPROFILE%\.workbuddy\skills
```

macOS / Linux 则是 `~/.workbuddy/skills`。

如果提示路径不存在，先打开一次 WorkBuddy，再试一次。

## 第 2 步：放进去

把本仓库的 `skills/product-rd-okr-writer` **整个文件夹**复制到上一步的目录里。

放好之后应该是这样：

```text
C:\Users\你的用户名\.workbuddy\skills\product-rd-okr-writer\SKILL.md
```

⚠️ **最常见的错误是多套了一层**。如果变成下面这样，工具读不到：

```text
...\skills\product-rd-okr-writer\product-rd-okr-writer\SKILL.md
```

## 第 3 步：验证

打开 WorkBuddy，新建一个任务，输入：

```text
@skill://product-rd-okr-writer
```

能调起来就装好了。

## 其他 AI 工具

技能就是个纯文本文件夹（`SKILL.md` + `references/`），没有专有格式，理论上多数工具都能加载：

| 工具 | 目录 |
| --- | --- |
| WorkBuddy | `%USERPROFILE%\.workbuddy\skills\` |
| Codex | `%USERPROFILE%\.codex\skills\` |
| Claude Code | `%USERPROFILE%\.claude\skills\` |

调用写法各家略有不同（WorkBuddy 是 `@skill://技能名`），放对目录后按你那个工具的用法调。

⚠️ **注意**：飞书读写那部分依赖 `lark-cli` 命令行**和 Python 3**，不是所有工具都能帮你调命令行。用别的工具时请确认它能执行本地命令，否则飞书相关功能不可用（技能本体的填写功能不受影响）。

> ⚠️ **如实说明**：**跨工具兼容性只在目录结构层面适配过，没有逐家实测。** 上面三个目录是常见惯例，不保证是各家当前的最新规范；装不上是可能的。
