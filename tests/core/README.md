# 核心检查

运行`python tests/core/check_package.py`可检查UTF-8、代码围栏、相对引用存在性、包内引用边界与资源可达性；只使用Python标准库，不是技能运行依赖，也不证明审核准确。

技能格式另用skill-creator的quick_validate验证。实际内容试用使用新输入与原始回复：应指出的问题能指出、合格内容不误报、建议具体且有用。覆盖正文与备注、类型门槛、关系证据及局部材料边界；另用起草请求核对同一知识可自然复用，不会被独立写作流程限制。

测试输入与预期分开，固定候选后保留实际回复；项目过程记录放在所属项目工作区，不把真实公司材料提交仓库。不因通过静态检查就宣称全部内容、安装发现或各宿主兼容通过。
