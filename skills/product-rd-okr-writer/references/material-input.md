# 可选外部材料交接

这是核心的材料读取约定，不要求用户填写表单，也不证明任何API已可用。粘贴文本、清楚的结构化文本或JSON均可；核心按相同[判据](okr-writing-rules.md)处理。

| 材料 | 保留或明确标缺 |
| --- | --- |
| 来源、对象 | 粘贴或飞书，实际读取时间；人员名称及定位ID；不含令牌或密钥 |
| 周期 | 周期名称、ID及可取得的起止时间 |
| 每个O | 原文、归属人员、周期、分类及其已知状态、原始定位标识 |
| 全部KR | 每条原文、父O归属及原始标识；原文中的数值和提及保留 |
| 对应备注 | O备注以及能明确对应的KR说明；不假定API必有独立KR备注字段，不将模糊备注套到每条KR |
| 完整性 | 是否分页取全、哪些字段缺失或未读、权限是否不足；区分确实无内容与未能取得 |
| 关系证据 | 用户明确说明的正式承接、原始系统对齐分开记录；系统对齐不自动证明正式承接 |

材料缺少分类、备注或关系时按已有规则保留缺口，不能降低判据或代造。不同成员和不同O的备注不混用；提及用于展示，比较副本才做归一化。真实读取需明确人员、周期及可见权限；失败时可请用户粘贴相应材料，不改身份扩大权限。

## 虚构材料样例（仅说明形态）

```text
来源：飞书脱敏整理样例（非真实API返回，未真实读取）
对象：成员甲，定位ID sample-a
周期：2026年第四季度，sample-q4，2026-10-01至2026-12-31
完整性：此成员仅提供O1；O1的KR已提供全部2条；整份O数量未知
关系：用户明确说明正式承接上级乙的检索性能KR；对齐字段未取得
O1 sample-o1：让订单检索稳定支撑一线排障
分类：承诺型（样例用户已确定）
KR1 sample-kr1：持续优化检索性能
KR2 sample-kr2：完成检索故障定位手册，覆盖样例用户给定的异常类型
O1备注：仅对应KR1，P95不超过600ms；范围为已列的订单查询接口，按周期内压测报告验收。
KR2说明：无独立字段，未取得其他验收说明。
```

该样例用于检查归属和缺口边界：不因KR1正文笼统就忽略备注，不把KR1的验收套给KR2，不推断成员整份只有一个O。不代表上述目标适用于任何真实用户，也不代表飞书接入已通过。
